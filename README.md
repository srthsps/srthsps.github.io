# srthsps.github.io

Website for Sarath PS's games and apps: https://srthsps.github.io

- `/wise-words/` — the Wise Words page, with its privacy policy and terms
- `/app-ads.txt` — authorised ad sellers (Google AdMob)

The Wise Words pages are generated from the game's own texts (`store/` in the game's repository):

```sh
python3 tools/build.py ../wise-words
```
